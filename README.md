## Dependências do projeto

As dependências são declaradas separadamente para o backend e o frontend:

### Backend (`backend/package.json`)

- `express` 5.2.1 — servidor HTTP e rotas da API.
- `multer` 2.2.0 — recebimento de arquivos enviados.

Os testes do backend usam o runner nativo do Node.js (`node:test`), sem dependência adicional.

### Frontend (`frontend/package.json`)

Dependências de produção:

- `react` 19.2.7 — biblioteca da interface.
- `react-dom` 19.2.7 — renderização da interface no navegador.

Dependências de desenvolvimento:

- `vite` 8.0.16 — servidor de desenvolvimento e ferramenta de build.
- `@vitejs/plugin-react` 6.0.3 — integração do React com o Vite.

O frontend declara requisito de Node.js `>=24`.
